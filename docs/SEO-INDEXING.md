# SEO and Indexing

Production hostname is `https://websitedesigndogs.com` from `NEXT_PUBLIC_SITE_URL`. Canonicals are absolute clean URLs without query strings. The sitemap includes `/`, `/services`, `/portfolio`, `/packages`, `/about`, `/contact`, `/faq`, `/get-started`, and the four legal pages. Campaign routes and API routes are excluded from the sitemap; campaign pages retain page-level `noindex,nofollow` and self-canonicals.

`robots.txt` allows public assets and pages, disallows `/api/`, and references `/sitemap.xml`; it does not block campaigns so crawlers can read the noindex directive. Structured data is limited to Organization, WebSite, BreadcrumbList where used, FAQPage, OfferCatalog/Offer, and campaign Offer. Omitted fields include LocalBusiness, address, telephone, social profiles, aggregate ratings, reviews, employee counts, awards, and unsupported location claims.

Verification variables are `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`, `NEXT_PUBLIC_BING_SITE_VERIFICATION`, and `NEXT_PUBLIC_META_DOMAIN_VERIFICATION`; set them in Vercel only after providers issue values. To validate: inspect page source for canonical and robots tags, visit `/robots.txt` and `/sitemap.xml`, use Rich Results/Schema validator for JSON-LD, inspect campaign pages for noindex, then submit sitemap in Google Search Console and Bing Webmaster Tools. Future indexable pages must get unique metadata, an absolute canonical, visible content, and sitemap inclusion. Do not create duplicate city/location pages or use LocalBusiness schema without verified location information.
